# Blitz Square Security Dashboard

A web-based apartment management dashboard built using HTML, CSS, and JavaScript.

## Features

- Flat Management
- Emergency Alerts
- Pooja Duty Scheduling
- Maintenance Tracking
- Activity Logs
- Local Storage Support

## Technologies Used

- HTML
- CSS
- JavaScript
